## Url Shortener Services

* [3.ly](https://3.ly) - A free URL shortener with custom slugs, QR code generation, click statistics, and password protection.
* [bit.ly](https://bitly.com) - An enterprise link management platform offering URL shortening, QR codes, link-in-bio pages, and detailed analytics.
* [bl.ink](https://www.bl.ink) - An enterprise link management and QR code platform with editable links, SOC2/HIPAA compliance, and dynamic routing rules (acquired by Loftware, April 2025).
* [buff.ly](https://buff.ly) - Buffer's built-in link shortener, automatically applied when scheduling social media posts through the Buffer platform.
* [cutt.ly](https://cutt.ly) - A link management platform with URL shortening, branded links, dynamic QR codes, link-in-bio pages, and A/B testing.
* [Dub.co](https://dub.co) - A modern link attribution platform with branded short links, conversion tracking, affiliate program management, and geo/device targeting.
* [Foxly](https://foxlyme.com/) - A branded URL shortening and link management platform with analytics, custom domains, and multiple pricing tiers.
* [han.gl](https://han.gl) - A URL shortening service offering trackable links, QR codes, bio pages, device/geo targeting, and bulk link generation.
* [is.gd](https://is.gd) - A minimalist URL shortener with custom alias support, optional click-tracking statistics, and pronounceable link format options.
* [KurzeLinks.de](https://kurzelinks.de) - A German privacy-focused URL shortener with malware scanning, QR code generation, password protection, and expiration dates.
* [Linkly](https://linklyhq.com) - A URL shortener and link tracking platform with built-in analytics, custom branding, QR codes, geo-targeting, and retargeting pixel support.
* [LinkSplit](https://linksplit.io/url-shortener) - A URL shortening platform with link rotation, traffic splitting, retargeting pixel support, custom domains, and real-time analytics.
* [name.com](https://www.name.com/branded-url-shortener) - Name.com's branded URL shortener powered by BL.INK, offering custom domain short links, editable destinations, and analytics.
* [oe.cd](https://oe.cd/) - The OECD's internal URL shortener, restricted exclusively to OECD-related URLs, with click statistics and category filtering.
* [rebrandly.com](https://rebrandly.com) - A branded link management platform with custom domain short links, QR codes, real-time analytics, SOC2/HIPAA compliance, and 100+ integrations.
* [short.io](https://short.io) - A branded URL shortening platform for creating custom short links on your own domain, with real-time analytics and QR code generation.
* [shorturl.at](https://www.shorturl.at) - A free URL shortening service with companion tools including a QR code generator, image compressor, and word counter.
* [SimpleURL](https://simpleURL.tech) - A link management platform with URL shortening, branded domains, QR codes, analytics, link-in-bio pages, and UTM campaign building.
* [smallseotools](https://smallseotools.com/url-shortener) - A free, no-registration URL shortener that converts long URLs into compact links using 301 redirects to preserve SEO value.
* [sor.bz](https://sor.bz) - A free, ad-free URL shortener with customizable links, password protection, expiration dates, and analytics for registered users.
* [spoo.me](https://spoo.me/) - A feature-rich URL shortener with custom short links, password protection, click limits, expiration dates, and detailed analytics.
* [switchy.io](https://switchy.io) - A link management and shortening platform with click tracking, analytics, and retargeting capabilities.
* [T2M](https://t2mio.com) - An all-in-one link management platform with branded short URLs, dynamic QR codes, A/B testing, and a 99.99% uptime SLA.
* [tinu.be](https://tinu.be) - A free, privacy-first URL shortener and QR code generator that tracks clicks without collecting personal data.
* [Tiny URL](https://tiny.cc) - A free URL shortening service with custom endings, click statistics, QR code generation, and optional user accounts.
* [T.LY](https://t.ly) - A URL shortening and link management platform with branded short links, QR codes, and detailed click analytics with team collaboration features.
* [urlr.me](https://urlr.me/en) - A European, GDPR-compliant URL shortener hosted in France, offering branded short links, advanced analytics, and API access.
* [v.gd](https://v.gd) - An ethically-minded URL shortener with over 90 million URLs shortened, supporting custom slugs and optional click statistics.
* [vo.la](https://vo.la/) - A URL shortening platform with short links, QR code generation, bio link landing pages, and team collaboration with analytics.
* [yaso.su](https://yaso.su/) - A combined URL shortening and paste-sharing utility platform with user account support.

## Self Hosting Opensource

* [Dub.co](https://dub.co) - An open-source link management platform for creating branded short links, tracking marketing attribution, and managing affiliate programs.
* [Eastlake](https://github.com/Likenttt/eastlake-cloudflare-worker-short-url) - A URL shortener built on Cloudflare Workers with a Next.js admin interface, supporting password protection, expiration times, and click tracking.
* [kutt](https://github.com/thedevs-network/kutt) - A free, modern, self-hostable URL shortener with custom domains, password protection, link expiration, analytics, and a RESTful API.
* [lstu](https://framagit.org/fiat-tux/hat-softwares/lstu/) - A self-hostable URL shortening service built with Perl and the Mojolicious framework, with an official hosted instance available.
* [Polr](https://polrproject.org) - A quick, modern, open-source link shortener built for self-hosting with custom branding and full data control.
* [pygmy](https://github.com/amitt001/pygmy) - An open-source, feature-rich Python URL shortener with custom slugs, link expiration, password protection, user accounts, and geographic analytics.
* [san.aq](https://github.com/neutronscott/sanaq) - A minimal PHP-based URL shortener with an HTTP API for shortening long URLs via curl.
* [shlink](https://shlink.io) - A self-hosted URL shortener for creating and managing shortened links under your own domain, with detailed visitor statistics.
* [Sink](https://github.com/ccbikai/sink) - A fast, secure link shortener with analytics that runs entirely on Cloudflare, featuring AI-assisted slug generation, device/country routing, and QR codes.
* [yourls](https://yourls.org) - A self-hosted URL shortening service with analytics, a bookmarklet, and an extensible plugin architecture.
